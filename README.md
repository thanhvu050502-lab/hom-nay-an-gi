# Hôm nay ăn gì?

Vòng quay chọn quán ăn, dessert, đồ uống theo mood, ngân sách và danh sách quán của riêng bạn.

- Trang tĩnh, không cần build: `index.html`, `manifest.webmanifest`, `icon.svg`.
- Dữ liệu lưu trong trình duyệt (localStorage). Dùng nút "Tải file sao lưu" / "Khôi phục" ở tab Lưu để chuyển dữ liệu giữa các máy.
- Deploy: Vercel (gói Hobby, miễn phí), Framework Preset "Other", không cần build command.
